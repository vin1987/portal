🗄 Data Backup & Archive
HOW IT WORKS

Work logs older than the chosen threshold are moved to Archive_WorkLogs_YYYY sheets.
Completed/Shipped/Cancelled POs older than the threshold are moved to Archive_POs_YYYY.
Archive sheets are named by year so data stays organised. Source data is only deleted after a successful copy.

⚠ IRREVERSIBLE — Once archived, rows are removed from the live sheet. Verify the preview before confirming.

Setup & Configuration
🔗 GOOGLE SHEETS CONNECTION
1

Create Google Sheet

Go to sheets.google.com → New spreadsheet → name it MFG OPS Log.
Copy the Sheet ID from the URL bar:
docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit

2

Add Apps Script Backend

Inside the sheet: Extensions → Apps Script → paste the entire apps_script_backend.gs file.
Replace YOUR_SHEET_ID_HERE on line 15 with your Sheet ID.

const SHEET_ID = 'your-sheet-id-here';
3

Deploy as Web App

Deploy → New Deployment → Web App

Execute as: Me    Who has access: Anyone

Click Authorize when prompted. Then open the Web App URL in your browser once to confirm it returns {"status":"ok"}.

4

Paste Web App URL

🔒 API KEY — SECURE YOUR SHEET

By default, your Apps Script URL is public — anyone who finds it can read your data.
Setting an API key means every request must include a secret token, blocking unauthorised access.

STEP-BY-STEP
  1. Open your Apps Script → find line: const API_KEY = '';
  2. Set it to any secret string: const API_KEY = 'mfgops-2024-secret';
  3. Redeploy (Deploy → New Deployment — NOT "Edit")
  4. Paste the same key below and save

⚠ The key is stored in your browser localStorage — it is NOT transmitted unless you make a request. Make sure every device/browser that uses this dashboard has the same key saved here.
